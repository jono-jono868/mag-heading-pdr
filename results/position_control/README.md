# 位置の近さだけの照合との対照

位置補正の照合を、地磁気を使わず推定位置の近さだけで行うもの（位置の近さだけの照合）に替えて、提案と比べた結果（論文 5.5 節の前半）。評価データ 32 系列と別のデータ IDOL 130 系列で、RoNIN と EqNIO のそれぞれについて比べた。**論文の本文に載せたのは**、表 A の位置誤差の差の HL（評価データの 2 本、IDOL の RoNIN の HL と Holm 後 p、被験者単位では検出できなかったこと）、評価データの RTE の差、表 B の誤った一致の割合（全体）、定数を学習データの RTE の条件で選び直したこと。それ以外（表 A・B のほかの列、表 C・D、設計データ、建物別、因果性の確認、系列ごとの値）は**載せていない補足**。全統計は [summary.json](summary.json)、表の数値は [summary.csv](summary.csv) と [constant_selection.csv](constant_selection.csv)、系列ごとの ATE・RTE は [per_series_test.json](per_series_test.json) と [per_series_idol.json](per_series_idol.json)。

- 位置誤差は ATE（RoNIN 公式の定義）の系列ごとの値。差は「提案 − 比べる照合」の Hodges–Lehmann 推定量（HL。負なら提案が小さい）で、括弧は 95% 信頼区間（系列のブートストラップ）。exact p は零（|差| < 1e-4 m）を除いた対の両側 Wilcoxon 検定、Holm 後 p は評価データと IDOL の RoNIN・EqNIO の 4 本にかけた補正。被験者単位の p は、被験者ごとに差を平均して符号を入れ替える並べ替え検定（15 被験者の全通り）。w = 0.128 m は大きな変化の目安、RTE は 60 秒の相対誤差。
- summary.csv の `comparison` 列は、`X vs baseline` が X − 補正なし、`proposed minus X` が提案 − X。`n_lower`・`n_higher` は左の誤差が小さい・大きい系列数、`comparator_` は右側の値、`p_holm_over_4` は 4 本にかけた Holm 後 p。

## 設計データでの結果と定数の選び方（探索的）

設計データ 35 系列では、提案 − 位置の近さだけの HL は RoNIN −0.080 [−0.414, +0.143]（p 0.532）、EqNIO −0.135 [−0.421, +0.054]（p 0.168）で、差を検出できなかった。w 超の悪化は、位置の近さだけの照合で 9 / 9 系列（RoNIN / EqNIO）、提案で 1 / 2 系列だった。

位置の近さだけの照合の定数（探索半径と距離の閾値）は、先に試した値（2.0 m、1.5 m）を含む 12 通りから、設計データと学習データ（RoNIN、85 系列）で選び直した。(1) 学習データの RTE が補正なしより有意に悪化する設定を外し（HL > 0 かつ p < 0.05）、(2) 残りのうち設計データの位置誤差（RoNIN と EqNIO の HL の平均）が最小のものを選んだ。結果は先に試した値と同じだった（太字）。外れた設定の中に、設計データで最も位置誤差を下げた緩い設定（探索半径 2 m、距離の閾値 3.0 m）がある。

## 計算の手順

1. **入力**: RoNIN・EqNIO が推定した速度の積分による位置と、端末姿勢で世界座標に直した地磁気。正解の位置は、評価と誤った一致の判定にだけ使う。
2. **提案**: 地磁気の鉛直成分と水平成分の大きさの並び（直前 8 m、0.25 m 間隔の格子、0.5 m ごとに照合）を、20 秒以上前の窓と同じ向き・逆向きで比べ、窓の差が min(0.6 × 起伏, 3 µT) 以下なら一致とする。候補は補正後の位置が min(15, 3 + 0.0463 × 道のり) m 以内のもの。定数は [configs/README.md](../../configs/README.md)。
3. **位置の近さだけの照合**: 磁場を使わず、候補は補正後の位置が 2.0 m 以内の過去の格子点。直前 8 m の窓の補正後の位置と候補の窓の補正後の位置の平均距離が最小のものを選び、1.5 m 未満なら一致。一致のあとは提案と同じ（直前の一致と向きがそろい、ずれの変化が 1 m 未満のときだけ、寄せ幅 0.1 で補正後の位置を寄せる）。コードの経路は `magpdr.position.revisit_correction.run` の `feat = "pos"`（評価の手順はこのリポジトリに含めない）。
4. **評価**: 系列ごとの ATE・RTE を補正なし・提案・各照合で求め、上の統計で比べる。誤った一致は、更新のうち今の位置と寄せた先が正解の位置で 5 m を超えて離れていたもの。大きな悪化は、補正なしより w を超えて悪化した系列で、提案と位置だけの対を exact McNemar 検定で比べた。
5. **因果性の確認**: 設計データの RoNIN・EqNIO で、位置の近さだけの照合（緩い設定を含む）と磁場の大きさだけの照合について、各系列の更新から最大 6 件を選び、直後で系列を切って計算し直した（計 1,212 件）。共通の格子点のずれと補正後の位置の差は、すべて 0 で、同じ一致が全件で再現した。評価データと IDOL では行っていない。

## 但し書き

1. 評価データは開発の途中の評価にも使っており、一度も見ていないデータではない。IDOL は、提案の位置補正を構成を変えずに評価したデータで、この比較は 2 回目の使用（構成と定数は変えていない）。位置の近さだけの照合の定数は、この 2 つのデータを使う前に決めた。ただし、12 通りの計算の前に選び方の規則を決めたことは、記録から第三者には確かめられない。
2. **この比較は、地磁気の照合の部分だけを替えたものではない。** 提案には位置の絞り込み・起伏の下限・距離の上限があり、位置の近さだけの照合にはない。また対照で選び直したのは探索半径と距離の閾値だけで、寄せ幅と連続性の条件は提案の値のまま（位置だけは更新が多いので、小さい寄せ幅なら緩い設定も条件を通ったかもしれない。未検証）。
3. 誤った一致の割合と大きな悪化の数の比較は、設計データでの試走で提案に有利に出たあとに、副次の指標として加えた。系列ごとの誤った一致の数は保存していないので、誤った一致の割合の差の HL と p は、ここにある値から再計算できない。
4. 差を検出できる大きさには限りがある。設計データのばらつきからの見積もり（正規近似、α = 0.0125、検出力 80%）では、評価データの 32 系列で 0.29〜0.52 m、IDOL の 130 系列で 0.14〜0.26 m（IDOL は同じばらつきという仮定）。
5. 学習データの 85 系列は RoNIN の学習に使われた系列で、補正による位置誤差の変化が補正しない方へ偏る。定数の選び方では RTE の悪化の条件にだけ使い、位置誤差は選定に使っていない。設計データは構成の選定に使ったデータなので、そこでの結果は確証ではない。
6. IDOL の建物別・建物を除いた結果は、評価のあとに、多重比較の補正なしで計算した記述。IDOL の被験者は建物をまたぐ。
7. 評価データと IDOL の結果は、リポジトリのコマンドでは再現できない。提案と補正なしの系列ごとの値は、[results/position_correction/](../position_correction/) の評価データと IDOL の値と、ATE・RTE とも差 0 で一致する。
