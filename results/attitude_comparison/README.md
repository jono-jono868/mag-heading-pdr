# 地磁気を常に使う姿勢との比較

入力を座標に直す姿勢を、地磁気を常に使う姿勢に差し替え、学習済みのモデルで推論し直した場合の位置誤差を、補正なし（端末姿勢に game rotation vector を使う）と比べた結果（論文 5.2 節）。**集計した値だけ**を載せる。計算のスクリプト、系列ごとの値、推論の出力は、このリポジトリに含めない。全統計は [summary.json](summary.json)、表の数値は [summary.csv](summary.csv)。

- **VQF 9 軸**: 地磁気を常に融合する姿勢推定器 VQF の 9 軸版（既定値。磁気外乱の棄却つき）。
- **Android rotation vector**: OS が地磁気も使って出す姿勢。記録のまま使い、平滑化しない。
- どちらも、系列の最初の時刻の標本 1 点で、姿勢を正解の初期姿勢に合わせた（補正なしと同じ合わせ方。以後の方位は姿勢のまま）。RoNIN と EqNIO の学習済みモデルは学習し直していない。
- 位置誤差は ATE（RoNIN 公式の定義）の中央値 [m]。差は「姿勢を差し替えた場合 − 補正なし」の Hodges–Lehmann 推定量（HL。負なら位置誤差が小さい）で、括弧は 95% 信頼区間。exact p は零（|差| < 1e-4 m）を除いた対の両側 Wilcoxon 検定。w = 0.128 m は大きな変化の目安。

## 但し書き

- rotation vector は OS の出力を平滑化せず、記録のまま使った。設計データでは、35 系列中 24 系列で、game rotation vector との相対で 1 標本に 5° を超える跳びがある（最大 159°）。
- 方位は、系列の最初の時刻の 1 標本で正解に合わせた。評価の始点（約 20 秒後）の方位で合わせ直した版は設計データだけで確かめた。最初の 1 標本で合わせたうえで、その時刻の方位を補正なしの方位に一致させた版でも、補正なしより大きく悪い（RoNIN の中央値は VQF 9 軸 9.9 m、rotation vector 14.2 m。補正なしは 3.5 m）。その時刻の標本で正解の姿勢に合わせる版は、補正なし自身が崩れる（RoNIN の中央値 139 m）ので、感度として読めない。
- RoNIN と EqNIO の重みは、主に game rotation vector の入力で学習されている。姿勢を差し替えるのは入力の座標だけで、重みは学習し直していない。
- 端末は 2 機種で、結果は端末で分かれる。rotation vector は Asus で VQF 9 軸より悪く、Samsung では差が検出できない。
- 評価データは、開発の途中の評価にも使っており、一度も見ていないデータではない。この比較には、学習や調整をする部分が無い（rotation vector は OS の出力、VQF は既定値）。
- 評価データの RoNIN の VQF 9 軸の行は、[results/heading_correction/vqf_reference.json](../heading_correction/vqf_reference.json)（`paper.tables` の主結果の表の「VQF 9 軸」）と、系列ごとの ATE の差が最大 8.5e-06 m で一致する。
