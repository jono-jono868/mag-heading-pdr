# 遅い方位誤差の分布と、方位補正で直せる範囲

補正なしの遅い方位誤差が系列によってどれだけ違うか、採用した方位補正がそれをどれだけ変えたか、補正点の数との関係を、設計データ・学習データ・評価データで示した結果（論文 5.3 節）。**集計した値と系列ごとの値**を載せる。計算のスクリプトはこのリポジトリに含めない。全統計は [summary.json](summary.json)、表の数値は [summary.csv](summary.csv)、系列ごとの値は `per_series_design.json`・`per_series_train.json`・`per_series_test.json`。

- **遅い方位誤差**: 推定した速度の向きから正解の速度の向きを引いた方位誤差の 300 秒の中心移動平均。系列ごとの二乗平均平方根（RMS）で測る。バックボーンは RoNIN。
- **群**: 補正なしの遅い方位誤差で、5° 以下・5° 超 10° 以下・10° 超に分けた。正解を使う事後の層別で、実際の歩行では分けられない。探索的な分析である。
- **採用した設定**: 提案した方位補正の採用した設定（観測雑音の標準偏差 29.8°）。
- 論文の本文に載せたもの: 設計データと評価データの分布（表 A の中央値・5° 超・10° 超）、評価データの群ごとの補正点の数と 10° 超の群の変化、設計データと学習データの 10° 超などの群の中央値（5.4 節の表 4。[correction_strength](../correction_strength/README.md)）。載せていない補足: 学習データの分布、設計データ・学習データの群ごとの補正点の数、系列ごとの値。

- 評価データの 10° 超の 8 系列では、中央値が 16.4° から 16.0° にとどまった。そのうち 4 系列は補正点が 0 点か 1 点だった（0 点は 1 系列）。評価データの補正点の数の中央値は、5° 以下の群で 6 点、5° 超 10° 以下で 1 点、10° 超で 2.5 点だった。
- 補正なしの遅い方位誤差が小さい群では、採用した設定でほとんど変わらなかった（5° 以下の群の中央値は、設計データで 3.0° から 3.2°、学習データで 1.1° から 1.3°、評価データで 3.1° から 2.8°）。
- 設計データの 10° 超の 2 系列では、21.2° が 15.8° になったが、2 系列だけの値である。補正点の観測だけを正解に置き換えても 15.7° までしか下がらなかった（正解を使う非因果の値で、原因を一般に示すものではない。論文の本文には載せていない）。

## 計算の手順

1. **入力**: RoNIN の学習済みモデルの補正なしの出力の速度と、位置の正解（Tango）から求めた正解の速度。補正をかけた場合は、採用した方位補正の補正角で速度を回した出力を使う。
2. **方位誤差**: 窓ごとに「推定した速度の向き − 正解の速度の向き」を −180° から 180° に折り返す。正解の速さが 0.2 m/s 以下の窓は使わない。
3. **遅い方位誤差**: 方位誤差の sin と cos を、窓の幅が 300 秒の中心移動平均でそれぞれ平均し、角度に戻す（使える窓だけで平均する）。系列ごとに、その二乗平均平方根を測る。
4. **群**: 補正なしの値が 5° 以下、5° 超 10° 以下、10° 超（境の値は 5° と 10°）。
5. **補正点の数**: 設計データと評価データは、直進判定器が選んだ候補から評価器が選んだ補正点の数。学習データは、正解の直進区間の候補から、評価器の交差検証の予測で選んだ数（実際の運用とは選び方が違う）。
6. 中央値は系列ごとの値の中央値。検定は行っていない。

## 但し書き

- 群は補正なしの遅い方位誤差による事後の層別で、探索的な分析である。10° 超の群は、設計データでは 2 系列、評価データでは 8 系列で、少数の系列の値から一般化できない。
- 評価データの値は、評価のあとに加えた集計である。評価データは開発の途中の評価にも使っており、一度も見ていないデータではない。
- 学習データは RoNIN の学習に使った系列で、補正点の選び方も有利なので、補正による変化は実際の値と違いうる。同じ機種（samsung1）の系列が多い群がある（学習データの 10° 超の群は 13 / 17 系列、設計データの 10° 超の群は 2 / 2 系列）。
- 遅い方位誤差は位置誤差ではない。位置誤差への影響は、強く直した場合を含めて [correction_strength](../correction_strength/README.md) に載せる。
- 設計データと評価データの位置誤差と補正点の数は、公開済みの [方位補正の結果](../heading_correction/design.json) と、系列ごとの ATE の差が最大 6.1e-06 m、補正点の数は全系列で一致する。
