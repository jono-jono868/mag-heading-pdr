# 補正を強くした場合の得と損

採用した設定のほかに、補正を強くする 2 つの方式を試し、遅い方位誤差と位置誤差がどう変わるかを設計データと学習データで比べた結果（論文 5.4 節、表 4、図 2）。**採用した設定の代わりに試した探索的な分析**で、評価データでは試していない。**位置誤差が下がるとは言えない**（下の結果）。集計、系列ごとの値、図 2 の元データを載せる。計算のスクリプトはこのリポジトリに含めない。全統計は [summary.json](summary.json)、表の数値は [summary.csv](summary.csv)、系列ごとの値は `per_series_design.json`・`per_series_train.json`、図 2 の元データは [figure_data_a011_2.json](figure_data_a011_2.json)。

- **採用した設定**: 提案した方位補正（観測雑音の標準偏差 29.8°）。
- **観測雑音 7.5°**: 補正点・外れ値への重みの下げ方は採用した設定のまま、観測雑音の標準偏差だけを 7.5° にした。
- **直近 3 点の中央値**: 補正点ごとに、直近 3 点の補正点の観測が示す方位のずれの中央値に、補正角を合わせ直す。
- 遅い方位誤差（RMS [°]）の定義は [heading_error_analysis](../heading_error_analysis/README.md)。位置誤差は ATE（RoNIN 公式の定義）[m]。表の値は群の中央値。群は補正なしの遅い方位誤差による事後の層別で、探索的な分析である。
- 差は「方式 − 採用した設定」の Hodges–Lehmann 推定量（HL。負なら小さい）。**代表値は、変化した系列だけの HL**。p は零でない対の Wilcoxon 検定（exact。零でない対が 50 を超えるときは正規近似）で、多重比較の補正前の値。変化した系列が 6 以下の群は検定が成り立たない（—）。w = 0.128 m は大きな変化の目安。
- 論文の本文に載せたもの: 表 A（論文の表 4）、学習データの 10° 超の差と Holm 補正後の p、設計データの 5° 以下と学習データのそれ以外の位置誤差の差、図 2、a011_2 と a046_2 の値。載せていない補足: 表 B の設計データの 5° 超 10° 以下・全体の行、被験者単位の p、変種、補正なしとの比較、最も悪化した系列、系列ごとの値。

## 計算の手順

1. **補正点と観測**: 補正点は採用した設定と同じ。最初の補正点の観測 φ₁ を基準にし、補正点 j の観測が示すずれを d_j = φ₁ − φ_j（−180° から 180° に折り返す。d₁ = 0）とする。設計データは直進判定器と評価器が選んだ点。学習データは、正解の直進区間を候補にして評価器の交差検証の予測で選んだ点で、実際の運用より有利。
2. **観測雑音 7.5°**: カルマンフィルタの観測雑音の標準偏差を 29.8° から 7.5° にする。ほかは同じ。7.5° は、観測雑音を小さくした場合を見る感度として置いた値。参考として、学習データのずれの小さい群で測った観測と予測の食い違いの標準偏差は 7.2°。
3. **直近 3 点の中央値**: 補正点 j で、補正角を直近 3 点の d の円形の中央値（円形平均のまわりに展開した中央値）にし、次の補正点まで保持する。2 点のあいだは円形平均、1 点のあいだは 0。最初の補正点より前は 0。3 点は、外れた補正点 1 個に耐える最小の数。
4. **変種（表 D）**: 直近 1 点、直近 5 点、跳びを落とす方式（σ = 8.4°、閾値は σ の 2.5・3・4 倍）。論文の表には載せていない。
5. **比較**: 系列ごとに遅い方位誤差の RMS と ATE を測り、差を取る。零差は |差| が 1e-3°（角度）・1e-4 m（位置）未満。HL は全対の Walsh 平均の中央値で、95% 信頼区間は系列のブートストラップ（2000 回）。p は零を除いた対の Wilcoxon 検定（零でない対が 50 以下は exact、超えるときは正規近似）。
6. **多重比較と被験者単位**: 表 D の 7 通りの p に Holm の方法をかける。被験者単位の p は、被験者ごとに差を平均し、符号を入れ替える全通り（14 被験者）で数える。

## 但し書き

- 強く直した方式は、採用した設定の代わりに試した探索的な分析。群は正解を使う事後の層別で、実際の歩行でどの群に入るかは分からない。評価データでは試していない。
- 位置誤差が有意に下がった群は無く、5° 以下の群（設計データ）とそれ以外の群（学習データ）では有意に悪化した。位置誤差が下がったのは設計データの 10° 超の 2 系列などで、学習データの 10° 超の群では差が有意でない。遅い方位誤差の低下は、多重比較の補正後は有意でない。
- 学習データは RoNIN の学習に使った系列で、補正点の選び方も有利。補正を入れた変化が悪く出やすい。同じ機種（samsung1）の系列が多い: 設計データの 10° 超は 2 / 2 系列、学習データの 10° 超は 13 / 17 系列（14 被験者）。
- 設計データは、提案の構成を選んだデータで、確証ではない。中央値の方式の定数 3 点は、外れた補正点への耐性から決めた。
